# MMO Board — Доска объявлений для MMO RPG

Веб-приложение для публикации игровых объявлений и поиска напарников. Пользователи могут создавать объявления, оставлять отклики, а авторы объявлений — принимать или отклонять их.

## О проекте

Сервис позволяет:
- Регистрироваться с подтверждением email.
- Создавать объявления с изображениями и форматированным текстом (через CKEditor).
- Оставлять отклики на объявления.
- Принимать или удалять отклики (только автор объявления).
- Просматривать личный кабинет с фильтрацией откликов по статусу.

## Технологический стек

- **Язык:** Python 3.11
- **Фреймворк:** Django 4.2
- **База данных:** SQLite (для простоты запуска)
- **Форматирование текста:** django-ckeditor
- **Контейнеризация:** Docker, Docker Compose
- **Тестирование:** Django TestCase (7 тестов)

## Структура проекта

- `MMO_board/` — корневая директория проекта Django.
- `mmo_board_chat/` — основное приложение.
  - `models.py` — модели (кастомный пользователь, категории, объявления, отклики).
  - `views.py` — логика обработки запросов.
  - `forms.py` — формы (регистрация, создание объявления, отклик).
  - `signals.py` — сигналы (автоматическая отправка email при регистрации).
  - `tests.py` — тесты (7 штук).
- `Dockerfile` — инструкция для сборки образа.
- `docker-compose.yml` — оркестрация веб-сервера.

## Архитектурные особенности

- Кастомная модель пользователя: Авторизация происходит по email (а не по username), что соответствует современным требованиям. Поле email уникально.
- Подтверждение email: При регистрации генерируется уникальный код, который отправляется на почту. Пользователь не может войти, пока не подтвердит email.
- Безопасность откликов: Принять или удалить отклик может только автор объявления (проверка прав во views.py). Пользователь не может принять свой собственный отклик.
- Конфигурация: Секреты (SECRET_KEY, пароли почты) вынесены в .env. В репозитории хранится только шаблон .env.example.
- Контейнеризация: Проект полностью докеризован. Запускается одной командой.

## Email-уведомления

Система автоматически отправляет письма в следующих случаях:
1. При регистрации — письмо с кодом подтверждения email

2. При создании отклика — уведомление автору объявления (через сигналы)

3. При принятии отклика — уведомление автору отклика (через сигналы)

Настройки почты выполняются через Yandex SMTP с использованием пароля приложения:
- SMTP-сервер: smtp.yandex.ru
- Порт: 465 (SSL) или 587 (TLS)
- Требуется полный email и пароль приложения
